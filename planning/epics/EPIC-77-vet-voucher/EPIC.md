# EPIC-77: Veterinary Voucher & Direct Clinic Donation System

## Overview
**Goal**: Enable donors to purchase veterinary service vouchers that rescuers can claim and clinics can redeem, creating direct support for animal medical care.
**Target users**: Donors wanting to support specific clinics, rescuers needing veterinary services, partner clinics redeeming vouchers.

- [ ] [S1] Partner veterinary clinic registration model and API (RAP-507) - 5 pts, P0, Backend
- [ ] [S2] Clinic service catalog with pricing (RAP-508) - 5 pts, P0, Backend
- [ ] [S3] Voucher purchase flow for donors (RAP-509) - 8 pts, P0, Fullstack
- [ ] [S4] VetVoucher model and lifecycle API (RAP-510) - 5 pts, P0, Backend
- [ ] [S5] Rescuer voucher wallet and claim flow (RAP-511) - 5 pts, P1, Fullstack

- [ ] [S9] Financial reconciliation dashboard (RAP-515) - 5 pts, P2, Fullstack
