# S02: Transport Request Creation Form

## Story
As a rescuer, I want a form to quickly request animal transport with details about pickup and destination.

## Acceptance Criteria
- [ ] /portal/transport/new form with fields: pickup address, destination, animal info, urgency, preferred date/time, notes
- [ ] Address auto-suggest using Google Maps API (optional)
- [ ] Map preview showing route if coords available
- [ ] Animal species/size selection
- [ ] Special needs textarea
- [ ] Urgency radio buttons: normal, urgent, emergency
- [ ] Form validation: required fields, valid addresses
- [ ] Success message on submit
- [ ] Mobile responsive layout

## Definition of Done
- [ ] Form functional and tested
- [ ] API integration working
- [ ] Mobile responsive
- [ ] Deployed to staging
