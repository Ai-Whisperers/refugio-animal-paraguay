# S02: Survey Creation Form

## Story
As an admin, I want an intuitive form to create surveys without writing JSON so that I can quickly design surveys to gather feedback.

## Acceptance Criteria
- [ ] Create /admin/surveys/new page with form
- [ ] Form fields: title (text), description (textarea), start_date, end_date
- [ ] Dynamic question builder: add/remove questions
- [ ] For each question: type (dropdown), question text, options (for radio/checkbox)
- [ ] Drag to reorder questions
- [ ] Preview survey before saving
- [ ] Publish with date range
- [ ] Clone existing survey feature
- [ ] Form validation: required fields
- [ ] Save as draft before publishing

## Definition of Done
- [ ] Form renders correctly
- [ ] Question builder working
- [ ] Drag-reorder functional
- [ ] API integration verified
- [ ] Mobile responsive
- [ ] Deployed to staging
